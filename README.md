## FritchiiLinux

A Linux build of [Lichii](https://github.com/zortos293/Lichii), packaged for [Bazzite](https://bazzite.gg) and other Fedora Atomic systems.

```bash
curl -fsSL https://raw.githubusercontent.com/viktorsparda/FritchiiLinux/nx2/tools/linux/bazzite-install.sh | bash
```

See [docs/Bazzite.md](docs/Bazzite.md) for Gaming Mode, building from source and troubleshooting.
